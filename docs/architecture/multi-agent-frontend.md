# 前端页面规划 — 多智能体 v2

---

## 1. 智能体管理页 `/settings/agents`

卡片式布局，每张卡片只显示用户快速理解这个智能体所需的信息。

```
┌─ 设置 > 智能体 ──────────────────────────────────────────┐
│                                                           │
│  [+ 新建智能体]                                           │
│                                                           │
│  ┌─────────────────────┐ ┌─────────────────────┐          │
│  │ 🛠️                  │ │ 📝                  │          │
│  │ 默认助手  [默认]     │ │ 代码审查员      [══] │ ← 滑块  │
│  │ 通用任务执行         │ │ 审查代码质量与安全  │          │
│  │                [编辑]│ │                [编辑]│          │
│  └─────────────────────┘ └─────────────────────┘          │
│                                                           │
│  ┌─────────────────────┐ ┌─────────────────────┐          │
│  │ 🔍              [  ]│ │ 📊              [══] │          │
│  │ 研究员               │ │ 数据分析师           │          │
│  │ 深度调研与文献综述   │ │ 数据清洗与可视化     │          │
│  │                [编辑]│ │                [编辑]│          │
│  └─────────────────────┘ └─────────────────────┘          │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

**卡片元素**：
- 头像 emoji
- 名称（粗体）
- 一行描述（灰色小字）
- 可见性滑块：`[══]` = 在对话页可选，`[  ]` = 隐藏
- `[默认]` 标签（仅默认智能体显示）
- `[编辑]` 按钮 → 打开编辑弹窗

**滑块含义**：控制该智能体是否出现在对话页的快速切换菜单中。不是"启用/禁用"——关闭后智能体仍然存在、仍然可编辑，只是在对话页的下拉菜单里看不到它。

## 2. 对话页 `/chat`

**智能体切换替代模型切换。** 选择智能体即同时选定模型、权限、提示词——不再有独立的模型选择器。

```
┌─ 对话 ───────────────────────────────────────────────────┐
│                                                           │
│  [🛠️ 默认助手  ▾]     ← 替代原来的模型选择器               │
│   ├── 📝 代码审查员    （只显示滑块开启的智能体）           │
│   └── 📊 数据分析师                                        │
│                                                           │
│  ┌──────────────────────────────────────────────┐ [发送]  │
│  │ 输入消息...                                  │        │
│  └──────────────────────────────────────────────┘        │
└───────────────────────────────────────────────────────────┘
```

## 数据流

```
管理页 滑块关闭 → PATCH /api/agents/{id} { hidden: true }
  → 对话页 GET /api/agents 过滤 hidden=false → 下拉菜单不显示

对话页 切换智能体 → POST /api/chat { agent_id: "adf_xxx" }
  → 后端用该智能体的 system_prompt + 权限 + 模型
```
