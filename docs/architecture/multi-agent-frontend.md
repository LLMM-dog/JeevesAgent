## 2. 群组管理页 `/settings/agent-groups`

```
┌─ 设置 > 智能体群组 ───────────────────────────────────────┐
│                                                            │
│  [+ 新建群组]                                              │
│                                                            │
│  ┌────────────────────────────────────────────────────────┐│
│  │ 👥 代码审查组 (MOA)                                     ││
│  │   并行审查 → 汇总                                      ││
│  │   成员: 🔒安全检查员 · ⚡性能分析员 · 📊汇总员           ││
│  │   ──────────────────────────────────────────  [编辑]   ││
│  ├────────────────────────────────────────────────────────┤│
│  │ 📋 发布工作流 (Workflow)                                ││
│  │   规划 → 执行 → 审查                                   ││
│  │   成员: 📐规划员 · 🛠️执行员 · 📝审查员                  ││
│  └────────────────────────────────────────────────────────┘│
└────────────────────────────────────────────────────────────┘
```

### 新建/编辑群组弹窗

```
┌─ 新建智能体群组 ────────────────────────────────┐
│                                                  │
│  名称 *         ┌──────────────────────────┐     │
│                 │ 代码审查组                │     │
│                 └──────────────────────────┘     │
│                                                  │
│  类型            ○ MOA (并行+汇总)               │

│    [1] 安全检查员 ▾  (worker)     [↑][↓][×] │     │
│    [2] 性能分析员 ▾  (worker)     [↑][↓][×] │     │
│    [3] 汇总员     ▾  (aggregator) [↑][↓][×] │     │

│                 [+ 添加成员]                      │
│                                                  │
│                              [取消]  [保存]       │
└──────────────────────────────────────────────────┘
```
